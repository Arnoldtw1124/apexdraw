# Apex 轉盤小幫手 - OBS 實況主專用隨機英雄與槍械輪盤

專為 OBS Studio 實況主打造的視覺化轉盤與觀眾連動插件，適用於《Apex 英雄 (Apex Legends)》。提供流暢卡片滾動輪盤、槍枝與英雄自訂篩選、Twitch 忠誠點數免設定連動、觀眾排隊名單管理與 OBS 完全透明圖層模式。

---

## 主要特色

- **雙動態橫向轉盤**：英雄與槍枝卡片滾動，精準停在中央指針。
- **Twitch 忠誠點數免設定連動**：不需要申請金鑰或搞懂 complicated 的 API 設定，輸入 Twitch 頻道名稱就能自動抓到觀眾兌換。
- **觀眾排隊名單與控制面板**：觀眾用點數兌換後自動排隊，提供實況主一鍵抽下一位與完成挑戰管理。
- **高可讀性垂直圖層**：針對 OBS 角落縮放優化，大字體與高對比視覺設計，放在直播角落超清楚。
- **防止音效重疊**：控制面板自動靜音，只有直播圖層會發出音效。

## 控制面板使用方式 (Control Dock Guide)

在 OBS 中打開控制面板後，您可以進行以下操作：

### 1. 設定 Twitch 頻道連動
- 切換至 **Twitch 連動** 分頁。
- 在「Twitch 頻道帳號」輸入您的 Twitch 帳號名稱（例如 `arnold1124`）。
- 點選「儲存並連動」即可自動偵測觀眾在您直播間兌換的忠誠點數。

### 2. 抽籤控制
- **一鍵全抽**：同時滾動英雄與槍枝轉盤，產生隨機組合。
- **單獨抽英雄 / 單獨抽槍枝**：僅隨機抽取其中一項。

### 3. 觀眾排隊佇列管理 (主頁)
- **當前挑戰玩家**：自動顯示目前排在第 1 位的觀眾名稱。
- **完成此局挑戰 (抽取下一位)**：完成遊戲後點擊此按鈕，系統會將目前的玩家推下，並自動讓候選序列的下位觀眾接替成為當前玩家。
- **清空佇列**：一鍵清除目前所有排隊中的觀眾名單。

### 4. 英雄與槍枝庫篩選
- 切換至 **英雄庫** 或 **槍械庫** 分頁。
- 可以勾選或取消勾選特定英雄與槍枝（例如不想玩某些武器時），轉盤將只會從您勾選的清單中進行抽籤。

## 網址參數設定說明 (進階)

若不想在控制面板內手動輸入頻道，也可以直接將參數帶在網址後面：

| 參數 | 範例 | 說明 |
| --- | --- | --- |
| `channel` / `twitch` | `?channel=your_username` | 自動填入並綁定指定 Twitch 頻道名稱 |
| `reward` | `?reward=抽隨機英雄和槍枝` | 指定觸發排隊的忠誠點數獎勵名稱 |
| `mode` | `?mode=dock` | 開啟實況主控制面板模式 |

## 本地端離線開發 (選填)

如果您想在自己電腦本機跑，或是想自己改程式碼：

1. 電腦先安裝好 Python 3.x。
2. 執行 `python server.py` 啟動本機伺服器 (Port 8000)。
3. 在 OBS 裡面的網址改成 `http://localhost:8000/` 或 `http://localhost:8000/?mode=dock`。
